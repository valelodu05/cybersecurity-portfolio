## Technical Focus Areas
- **Application Security (AppSec):** White-box source code auditing (SAST), runtime binary instrumentation (DAST), and cryptographic weakness remediation aligned with OWASP Top 10 and CWE.
- **Network & RF Security:** 802.11 protocol resilience auditing, 4-way handshake analysis, and passive 1090 MHz ADS-B telemetry decoding via Software-Defined Radio.
- **Secure Software Development:** Modular CRUD web architecture design, relational data modeling, and input validation principles.
